# Полиномиальная регрессия

Курс «Основы машинного обучения»  
Команда 18: Савосина Дарья, Андреев Александр

## Содержание каталога

| Файл | Содержание |
| --- | --- |
| `Полиномиальная регрессия.pdf` | Презентация, 21 слайд |
| `src/numerical_example.py` | Расчёт полиномиальной МНК-регрессии на пяти точках |
| `src/experiment.py` | Подбор степени и регуляризации, сравнение с другими моделями |
| `src/requirements.txt` | Версии библиотек |
| `readme.md` | Описание работы и команды для запуска |

## Запуск

В папке проекта установите библиотеки:

```bash
python -m pip install -r src/requirements.txt
```

Потом запустите примеры:

```bash
python src/numerical_example.py
python src/experiment.py
```
